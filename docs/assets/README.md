# Documentation assets

Keep diagrams and images here only when they materially help explain XingChen.
Prefer editable source formats and document provenance/licensing. Do not add
decorative AI-generated artwork or brand assets without an agreed visual
direction.

Before committing images, inspect every frame and remove API keys, tokens,
cookies, administrator/account identifiers, private chat content, QQ group
details, public server addresses, and browser/session data.

No banner or logo is currently published.
